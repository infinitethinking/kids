# kids

Weekly training planner (`index.html`).

Once GitHub Pages is enabled, the site is at:
https://infinitethinking.github.io/kids/

## Enable GitHub Pages

`index.html` is already on `main`. Pages still has to be turned on in the repository settings (this cannot be done from a workflow or pull request):

1. Open [Pages settings](https://github.com/infinitethinking/kids/settings/pages).
2. Under **Build and deployment** → **Source**, choose **GitHub Actions**.
3. After this pull request is merged, the deploy workflow publishes the site. You can also run **Actions → Deploy static content to Pages → Run workflow**.

Alternatively, choose **Deploy from a branch**, then **main** and **/(root)**.
